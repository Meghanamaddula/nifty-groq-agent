# Nifty50 Analysis using Groq AI

## Overview

This project analyzes Nifty50 stocks using Python, Pandas, yFinance and Groq AI.

The project contains multiple AI agents that provide:

- Company-wise stock analysis
- Sector-wise stock analysis
- Volume analysis
- AI-powered market insights

## Technologies Used

- Python
- Pandas
- yFinance
- Groq API
- GitHub

## Project Files

### company_agent.py
Analyzes individual company stocks.

### sector_agent.py
Analyzes sector performance.

### groq_nifty_agent.py
Main AI agent for stock analysis.

### groq_nifty_volumes.py
Analyzes stock trading volumes.

### normal_nifty_volume.py
Performs standard volume calculations.

### requirements.txt
Contains project dependencies.

## Installation

Install required libraries:

```bash
pip install -r requirements.txt
```

Create a .env file:

```env
GROQ_API_KEY=your_api_key
```
